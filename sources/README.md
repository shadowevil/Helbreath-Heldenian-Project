# Sources

Source code for the Helbreath client, server, shared protocol code, the SFML engine layer and the CControls
UI library. Build and layout instructions: `.claude/docs/build.md`; project structure: `.claude/docs/architecture.md`; binding rules: the repository's `CLAUDE.md`.

## Helbreath reference: source of truth

The **Original-Helbreath** GitHub organization is the source of truth for all of Helbreath:
<https://github.com/orgs/Original-Helbreath/repositories>

Its repositories can answer almost any question about Helbreath, such as original game logic, protocol and
packet formats, data files, formulas, maps, items and NPCs. Check there before guessing at original
behaviour or reverse-engineering it from this code.
